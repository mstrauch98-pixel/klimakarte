🌍 Unsere Klimakarte

➕ Einen Beitrag zur Klimakarte hinzufügen

So geht's:
1. Gib den Ort ein.
2. Klicke auf „📍 Ort auf Karte auswählen“ und anschließend auf die gewünschte Stelle auf der Karte.
3. Trage eure Untersuchungsergebnisse ein.
4. Klicke auf „Beitrag absenden“.
Noch keinen Ort ausgewählt.
ℹ️ Dein Beitrag wird zunächst geprüft. Erst nach der Freigabe durch die Lehrkraft erscheint er auf der gemeinsamen Klimakarte.
